# 测试说明

本目录包含水果销售系统（依据 `design/trade_sys_0822.umlproj` 生成）的测试用例。

## 用例文件

- `test_trade_sys.py`：三条核心顺序图流程的端到端冒烟用例（含库存不足拒绝分支）。
- `test_flows_extended.py`：关键流程补充用例，覆盖主路径与分支：
  - **Place Order Flow**：无优惠、未达门槛、满减券、折扣券、VIP 叠加、重复支付拒绝、取消订单、非法购物车。
  - **库存服务分支**：出库超量失败、未知商品查库存、非正数入库、入库记录。
  - **Procurement Stock-in Flow**：报价回填单价、到货入库与重复确认、取消后拒绝到货、供应商管理。
  - **Sales Report Generation Flow**：日报销售额/毛利/排行、空日期零值、月报聚合、库存报表预警、导出不存在报表。
  - **支撑能力**：登录与改密、停用用户约束、角色权限、购物车合并/移除/改量、优惠券校验。

## 运行方式

在项目根目录执行：

```
cd test
python -m pytest -q
```
