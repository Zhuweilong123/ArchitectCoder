# 插件演示资源 / Plugin demo assets

[中文教程](../../plugin-quickstart.md) · [English guide](../../plugin-quickstart.en.md)

| 文件 / File | 内容 / Contents |
|---|---|
| `plugin-architecture-zh.html` / `plugin-architecture-en.html` | 中英文单文件离线架构浏览器 / Standalone offline architecture viewers |
| `task-notes-zh.svg` / `task-notes-en.svg` | 应用真实渲染器生成的插件详情预览图 / Plugin detail previews generated by the application's renderer |
| `plugin-plan.json` | 上述文件共同使用的公开示例计划 / Shared public demo plan |

计划来自仓库的七个内置插件与 `examples/plugins/task_notes/plugin.json`，使用声明默认值。生成过程不读取应用 `.env`、不创建 Provider、不调用模型、不执行阶段处理器。来源路径为仓库相对路径；未包含私有部署配置、任务 Trace 或人为添加的诊断。预览是生成的架构图，不是应用截图。

The plan uses the seven built-in plugins and `task_notes`, with declaration defaults. Generation does not read the application `.env`, construct Providers, call models or execute phase handlers. Sources are repository-relative paths. No private deployment settings, task traces or invented diagnostics are included. Previews are generated diagrams, not application screenshots.

HTML 内嵌图形、脚本与样式，无需后端、CDN 或构建工具。下载原始 `.html` 文件后在浏览器打开，两个语言版本功能相同。导出时的声明状态不代表运行时健康状态。

HTML embeds graphics, scripts and styles. Open the downloaded raw `.html` file in a browser; no backend, CDN or build tools are needed. Both languages provide the same interactions. Declaration status does not imply runtime health.

## 重新生成 / Regenerate

安装后端依赖和前端依赖后，从仓库根目录执行 / After installing backend and frontend dependencies, run from the repository root:

```shell
python examples/plugins/export_demo_plan.py
node examples/plugins/export_demo.cjs
```

复用生产清单编译器、HTML 导出器及图形渲染器，更新插件声明或相关渲染代码后可重新生成。内容指纹和计划 ID 会随源码变化，应用本地计划也可能因配置与路径不同而具有不同 ID。

These commands reuse the production manifest compiler, HTML exporter and graph renderer. Regenerate after changing declarations or rendering code. Fingerprints and plan IDs change with source; a local application plan may have a different ID due to its configuration and source paths.

如需将验证产物放入临时目录 / To generate temporary outputs instead:

```shell
python examples/plugins/export_demo_plan.py --output temp/plugin-demo/plugin-plan.json
node examples/plugins/export_demo.cjs temp/plugin-demo/plugin-plan.json
```
