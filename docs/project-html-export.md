# 项目 HTML 导出

在工具栏选择 **导出设计 → 导出项目 HTML（离线阅读）**，下载 `<项目名>_design.html`。用现代浏览器直接打开该文件即可阅读，无需启动 ArchitectCoder 或连接网络。

文件包含项目内的全部类图、组件图和时序图，以导出时的图形与主题为准。左侧目录按项目中的图顺序排列，打开时默认显示导出前正在编辑的图。

## 阅读操作

- 点击目录切换图。
- 使用 `+`、`−` 按钮或滚轮缩放；滚轮缩放以鼠标位置为中心。
- 按住鼠标左键拖动平移，也可以用触屏单指拖动。
- 点击“适应窗口”完整查看当前图，点击“原始大小”恢复 100% 并居中。
- 聚焦图区域后，可以按 `+`、`−` 缩放，按 `0` 适应窗口。

图形、样式和交互脚本均内嵌在单个文件中。阅读器提供中英文界面，语言取自导出时的应用设置。窗口大小改变后会重新适应当前图。

## 当前范围

HTML 是只读的图形快照；元素展示内容与现有 SVG 导出一致。它不包含搜索、元素详情、跨图跳转或编辑功能。需要继续编辑设计时，使用 `.umlproj` 项目导出。

导出复用现有 SVG 生成流程，逐张渲染项目图形，并显示进度。成功或失败后恢复原图、视图位置、选择、修改标记和撤销/重做记录。图形导出失败时不会下载缺图的 HTML 文件。

文件体积随图的数量和复杂度增长。SVG 作为内嵌图片展示，项目名称和图名称经过转义；阅读器没有外部依赖或网络请求。

## 开发验证

在 `frontend` 目录运行：

```sh
npm run test:html
npm run build
```

自动化测试覆盖名称转义、数据完整性、中英文、默认图、目录切换、缩放、平移、适应窗口以及图片加载错误处理。浏览器人工验收应再检查真实类图、组件图和时序图的离线显示，以及导出前后编辑状态的恢复。
